# NODAL visual system

NODAL is an AI automation studio for operations teams that have outgrown manual handoffs. The landing page must make automation feel tangible, controlled, and business-ready rather than mystical.

## Signature

Luminous routing rails connect the page's visual language: they divide the hero triptych, appear inside service illustrations, and converge in the orchestration core. This is the one expressive device; the rest of the interface stays editorial and precise.

## Tokens

- Carbon `#090b0a`: immersive surfaces.
- Ink `#141714`: primary text.
- Paper `#f7f9f1`: operational surfaces.
- Signal lime `#9cff1e`: active routes and primary action.
- Moss `#183607`: inactive capability tracks.
- Steel `#70776d`: supporting text.
- Grid `#dff1d1`: technical grid lines.
- Coral `#f06c4f`: case-study accent only.

Display type is Sora. Body type is Manrope. IBM Plex Mono is reserved for system labels, indices, and status information.

## Layout

The maximum frame is 1400px. Desktop gutters are 56px, tablet gutters 32px, and mobile gutters 20px. Dark sections are immersive; light sections are structured around a faint 24px technical grid. Section rhythm alternates between full-bleed visual moments and constrained editorial content.

## Interaction

Motion communicates routing: horizontal drift, path drawing, and carousel translation. It never blocks reading. `prefers-reduced-motion` removes continuous motion and settles all content in place.
